# Duplar Móveis

Site institucional de página única para móveis planejados sob medida.

Stack: HTML, CSS e JavaScript sem build. Arquivos do site na raiz, imagens em `assets/img/`.

Fluxo previsto: `main` para versão-base e `develop` para alterações e pré-visualizações. O Netlify já está conectado ao GitHub, com `main` como branch de produção. A branch `develop` é dedicada a testes e pré-visualizações, após habilitar os Branch Deploys no painel.

> A seção de contato ainda usa dados provisórios indicados no briefing. Não substituir por dados inventados.
